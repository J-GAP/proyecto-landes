# 4) Nail an MVP

## 4.1 What the MVP is

El MVP del proyecto será una aplicación de **solo visualización**, enfocada exclusivamente en entregar información existente de forma clara, rápida y confiable.

El sistema no permitirá crear, modificar ni eliminar datos en esta primera versión.

## 4.2 MVP — Included (absolute minimum)

El MVP incluye únicamente:

* Acceso al sistema mediante código QR
* Identificación inmediata del equipo:
    * Nombre del equipo
    * Marca
    * Número de serie
* Visualización de ficha técnica básica del motor
* Visualización de:
    * Últimos 5 mantenimientos preventivos
    * Últimas 5 detenciones
* Visualización de un indicador simple del porcentaje de tiempo detenido

> [!NOTE]
> 👉 Todo el contenido es read-only.

## 4.3 MVP — Explicitly excluded

El MVP no incluye:
* Registro de mantenimientos
* Registro de detenciones
* Edición de información del motor
* Gestión de stock
* Autenticación avanzada
* Dashboards complejos

## 4.4 Why this MVP is enough

Este MVP cumple el objetivo principal del proyecto porque:
* Entrega valor inmediato al técnico en terreno
* Reduce el tiempo de acceso a información crítica
* Demuestra integración con datos reales de la empresa
* Es alcanzable en el contexto de una práctica profesional
* Deja la puerta abierta a futuras extensiones
